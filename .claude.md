#### Known issues / fixes applied
- `.venv` was created with a stale shebang pointing to `/workspace/python/my-fapi/.venv/bin/python` — fixed to `/workspace/my-fapi/.venv/bin/python`
- `uvicorn` and `fastapi` scripts in `.venv/bin/` were missing execute permissions — fixed with `chmod +x`
- `src/my_fapi/app.py` was empty — added minimal FastAPI app with a `GET /` route
- Old uvicorn background processes bind to `localhost` instead of `0.0.0.0`, blocking host access — kill with `kill <PID>` (use `lsof -i :8000` to find PIDs); `fuser` is not installed in this container
- Correct run command: `uv run uvicorn my_fapi:app --app-dir src --host 0.0.0.0 --port 8000`

#### Git config
- Git commits were showing author "Mitali Pagote" — fix by setting global git identity:
  ```bash
  git config --global user.name "Nikhil"
  git config --global user.email "your@email.com"
  ```
- Editor is **Zed** — SSH agent forwarding is NOT automatic (unlike VS Code)
- SSH agent forwarding configured in `docker-compose.yml` via `${SSH_AUTH_SOCK}:/ssh-agent`
- Before starting the container, run on host:
  ```bash
  eval $(ssh-agent -s)
  ssh-add ~/.ssh/id_rsa
  ```
- Rebuild container after `docker-compose.yml` changes for them to take effect
